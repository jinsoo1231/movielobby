# MovieLobby 모바일 기능 동기화 로드맵 (Mobile Sync Plan)

이 문서는 웹사이트(`app/`)에 존재하는 기능들을 모바일 앱(`mobile/`) 환경에 100% 동기화하기 위한 단계별 개발 체크리스트입니다. 기능이 개발될 때마다 완료(`[x]`) 상태로 최신화합니다.

---

## 📌 전체 진행 상황 요약
- **전체 단계**: 5개 Phase
- **현재 진행 단계**: Phase 3 완료 ✅ (Phase 4 준비 중)

---

## 🎬 Phase 1. 영화 상세: 한줄평(리뷰) 작성 및 추천/비추천 투표
> **목표**: 모바일 영화 상세 페이지에서 직접 별점과 한줄평을 남기고, 다른 유저의 리뷰에 추천/비추천을 누를 수 있도록 구현

- [x] **1-1. 한줄평 작성 인터랙티브 UI 구현**
  - [x] 별점 선택 UI (5개 별 인터랙티브 터치 선택기, 10점 만점)
  - [x] 200자 제한 한줄평 텍스트 입력창 및 실시간 글자수 카운터
  - [x] 로그인 사용자 닉네임 자동 연동 및 비로그인 시 로그인 유도
  - [x] Supabase `reviews` 테이블 insert 및 성공 시 리뷰 목록 & 평균 평점 즉시 갱신
- [x] **1-2. 리뷰 1인 1회 추천/비추천 투표 (`vote_logs`)**
  - [x] 리뷰 카드 내 좋아요(👍)/싫어요(👎) 카운터 및 버튼 배치
  - [x] `vote_logs` 테이블 조회 및 중복 투표 방지/취소/전환 로직
- [x] **1-3. Talks 연계 버튼 추가**
  - [x] 상세 상단/리뷰 영역에 "Movie Talks 커뮤니티" 바로가기 배너 버튼 추가
