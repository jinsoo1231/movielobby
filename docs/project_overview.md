# MovieLobby Project Overview

이 문서는 세상의 모든 영화에 대해 자유롭게 이야기하고 정보를 나눌 수 있는 'MovieLobby' 웹사이트의 주요 기능과 현재까지 개발된 내역을 소개하는 문서입니다.

## 1. 메인 홈 (Home & Trending)
- **트렌딩 영화 제공**: TMDB API를 연동하여 현재 가장 인기 있는(Trending) 영화 목록을 실시간으로 가져와 직관적인 카드 형태로 제공합니다.
- **자체 리뷰 평점 노출**: TMDB 기본 별점뿐만 아니라, MovieLobby 상세페이지에서 유저들이 직접 남긴 자체 리뷰 평점 평균값을 리스트 카드에 함께 노출하여 유저 참여형 플랫폼의 특징을 강화했습니다.
- **모던한 UI 디자인**: 깔끔한 흰색 배경 위에 다크 블루 컬러와 모던 시안/스카이블루 포인트를 조합하고, 평점 별점을 선명한 레드 컬러로 구현하여 심플하면서도 시인성이 매우 뛰어난 모던 UI를 완성했습니다.

## 2. 영화 상세 정보 (Movie Detail)
- **기본 정보 및 미디어**: 영화의 평점, 러닝타임, 개봉일, 감독, 출연진 등 핵심 정보와 함께 고화질 백드롭 이미지, 유튜브 트레일러 영상, 스틸컷 갤러리를 제공합니다.
- **프랜차이즈 타임라인**: 마블, 스파이더맨 등 시리즈물인 경우, 해당 영화가 속한 전체 컬렉션의 개봉 순서와 타임라인을 한눈에 볼 수 있습니다.

## 3. 톡스 커뮤니티 게시판 (Movie Talks)
- **영화별 전용 게시판**: 각 영화마다 유저들이 감상평과 토론을 나눌 수 있는 전용 커뮤니티 공간이 제공됩니다. (Supabase 데이터베이스 연동)
- **실시간 소통 및 추천**: 게시글 작성 기능이 실시간으로 반영되며, 유저들끼리 서로의 리뷰에 좋아요(추천)/싫어요를 남겨 의견을 나눌 수 있습니다.

## 4. 스포일러 방지 시스템 (Spoiler Protection)
- **스포일러 체크 기능**: 글 작성 시 스포일러 여부를 미리 체크하여 글을 보호할 수 있습니다.
- **2중 보호 장치**: 스포일러가 포함된 글은 게시판 목록에서 빨간색 `[스포일러]` 뱃지가 달립니다. 상세 페이지 진입 시 본문 내용이 블러(Blur) 처리되며, "클릭해서 보기" 버튼을 눌러야만 내용을 확인할 수 있어 치명적인 스포일러를 완벽하게 방지합니다.

## 5. 게시판 페이징 및 필터 검색 (Pagination & Search)
- **데이터베이스 최적화 (페이징)**: 게시판 진입 시 한 페이지당 15개의 게시글만 렌더링하도록 통신을 최적화하였으며, 하단에 동적인 페이지 번호(1, 2, 3...) 버튼이 제공됩니다.
- **다중 조건 검색**: 제목만, 본문만, 제목+본문, 작성자 등 다양한 조건으로 커뮤니티 내의 특정 글을 쉽게 찾아볼 수 있습니다.

## 6. 글자수 제한 및 Talks 연계 (Text Length Limit & Guidance)
- **한줄평 리뷰 글자수 제한**: 영화 상세 페이지의 한줄평 리뷰 작성 시 최대 200자 제한과 실시간 글자수 카운터를 제공합니다.
- **Talks 게시판 작성 유도**: 더 깊이 있는 감상평이나 긴 글을 작성하고자 하는 유저를 위해 한줄평 입력창 상단에 "더 긴 글은 Talks 게시판에서 작성하기" 바로가기 버튼을 배치했습니다.
- **게시글 본문 글자수 제한**: Talks 게시글 작성 시 최대 5,000자 제한을 두어 시스템 과부하를 방지하고 가독성을 확보했습니다.

## 7. 소셜 인증 및 회원 시스템 (Social Auth & User Onboarding)
- **간편 소셜 로그인**: Supabase Auth를 연동하여 구글(Google) 및 카카오(Kakao) 계정으로 원클릭 로그인을 지원합니다.
- **신규 유저 온보딩**: 소셜 로그인 최초 가입 시 전용 온보딩 화면을 통해 닉네임을 설정할 수 있도록 안내합니다.
- **헤더 유저 프로필 및 상태 관리**: 로그인 유저의 닉네임과 아바타를 헤더에 표시하며, 드롭다운을 통해 마이페이지 이동 및 원클릭 로그아웃을 지원합니다.
- **마이페이지(My Page)**: 내 프로필 정보(닉네임 수정 가능)와 내가 작성한 게시글 및 한줄평 리뷰 목록을 한눈에 모아보고 바로 이동할 수 있습니다.

## 8. 1인 1회 투표 제한 시스템 (Vote Logs & 1-Vote Limit)
- **중복 투표 방지 (`vote_logs`)**: 게시글 및 한줄평 리뷰의 추천(좋아요)/비추천(싫어요) 기능을 고도화하여 중복 어뷰징을 방지했습니다.
- **로그인/비로그인 지원**: 로그인 사용자는 고유 유저 ID 기반으로 판별하며, 비로그인 방문자도 브라우저 고유 클라이언트 식별자(UUID)를 활용하여 투표 이력을 추적합니다.
- **투표 취소 및 변경 지원**: 이미 누른 추천/비추천 버튼을 다시 클릭하면 투표가 취소(0으로 롤백)되며, 반대 버튼 클릭 시 즉시 상태가 전환되어 직관적인 사용자 경험을 제공합니다.

## 9. 모바일 앱 환경 구축 및 기능 동기화 (React Native & Expo)
- **모바일 네이티브 전환**: 기존 웹 플랫폼을 모바일 네이티브 앱(Android/iOS)으로 확장하기 위해 React Native와 Expo Router 기반의 하단 탭(Tab) 네비게이션 구조를 구축했습니다.
- **[Mobile] 4가지 핵심 탭 연동**: Home(트렌딩/디테일), Search(디바운스 검색), Talks(트렌딩 통합 커뮤니티), My(인증/프로필) 탭을 구현하여 앱 내에서 끊김 없는 사용성을 확보했습니다.
- **[Mobile] 통합 데이터베이스 동기화**: 웹 플랫폼과 동일한 Supabase 데이터베이스 및 TMDB API를 연동하여, 평점, 게시글 조회, 커뮤니티 목록이 웹과 실시간으로 완벽하게 동기화됩니다.
- **[Mobile] 모바일 최적화 미디어 플레이어**: 안드로이드/iOS 기기에서의 웹뷰(WebView) 에러 및 한계점을 극복하기 위해 `react-native-youtube-iframe` 전용 플레이어 모듈을 도입하여 매끄러운 영화 예고편 시청 환경을 제공합니다.
- **[Mobile] 글로벌 인증 및 마이페이지 통합 폼**: AsyncStorage와 AuthContext를 통한 로그인 유지 시스템과 하나의 화면에서 비밀번호 찾기와 회원가입을 부드럽게 오가는 크로스플랫폼(Cross-platform) 통합 인증 모듈을 구축했습니다.
- **[2026-08-22] Mobile - 톡스 커뮤니티 (Phase 2 & 3 완료)**:
    - 게시판 검색 및 최신 인기 영화의 전용 톡스 게시판 진입 기능
    - 영화별 전용 커뮤니티 게시판(`talk-board`) 내 BEST 글 및 일반 글 목록 렌더링
    - 모바일 인앱 새 글 작성(스포일러 방지 기능 포함) 
    - 조회수 동기화, 게시글 1인 1회 추천/비추천 투표 연동
    - 스포일러 게시글의 2중 블러(Blur) UI 해제
    - 실시간 댓글 등록 및 커뮤니티 댓글 목록 동기화, 투표, 댓글 기능(Phase 2)을 모바일 앱 환경에 100% 동일하게 구현 완료. 상세 페이지에서 인터랙티브 터치 별점(10점 만점) 선택과 200자 제한 한줄평을 직접 작성/등록할 수 있으며, `vote_logs` 연동 1인 1회 추천(좋아요)/비추천(싫어요) 투표 기능을 지원합니다.

## 10. 스토어 심사 대비 개인정보 보호 및 탈퇴 규정 준수
- **개인정보처리방침 (Privacy Policy) 구축**: 구글 플레이 콘솔 등 앱 마켓 등록 시 필수로 요구되는 개인정보처리방침 규정을 준수하기 위해, 웹사이트 내에 전용 페이지(`app/privacy/page.tsx`)를 구축하였습니다. 노션 등 외부 링크에 의존하지 않고 공식 도메인으로 서비스하여 유저 신뢰도를 높였습니다.
- **[Mobile] 회원 탈퇴 및 앱 내 연결 기능**: 앱 스토어 심사 필수 요건인 '사용자 계정 삭제 권리'를 충족하기 위해, 모바일 앱 마이페이지 내에 원클릭 회원 탈퇴 로직 및 개인정보처리방침 바로가기 기능을 구현했습니다.

## 11. 구글 플레이 스토어 마켓 출시 (Google Play Store Release)
- **비공개 테스트(Closed Beta) 배포 완료**: React Native(Expo) 기반의 `.aab` 프로덕션 빌드본을 추출하여 구글 플레이 콘솔에 업로드하고, 최초 출시 노트를 작성하여 비공개 테스트 심사를 제출했습니다.
- **마켓플레이스 자산 고도화**: 스토어 노출 최적화를 위해 구글이 요구하는 엄격한 비율과 투명도 조건(Alpha channel 제약)을 준수한 고해상도 그래픽 이미지(1024x500) 및 패딩 처리된 스크린샷 에셋 가공을 자체 완료했습니다.
