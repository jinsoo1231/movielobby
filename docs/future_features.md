# Future Features to Implement

이 문서는 MovieLobby 커뮤니티의 활성화와 완성도를 높이기 위해 앞으로 추가해야 할 핵심 기능들을 정리한 기획서입니다.

## 1. 인기글 / 베스트글 정렬 기능 (Sorting)
- **내용**: 현재 무조건 '최신순'으로만 표시되는 게시판 상단에 `[최신순 | 조회수순 | 좋아요순]` 탭을 추가합니다.
- **기대 효과**: 영화 개봉 직후 사람들이 가장 많이 토론하고 공감한 "베스트 리뷰"나 "뜨거운 논쟁거리"를 한눈에 볼 수 있어 커뮤니티가 훨씬 활성화되어 보입니다.

## 2. 이미지 첨부 기능 (Image Upload)
- **내용**: 글 작성 시 텍스트뿐만 아니라, 영화 스크린샷이나 재미있는 밈(짤)을 업로드할 수 있도록 기능을 추가합니다. (Supabase Storage 활용 예정)
- **기대 효과**: 영화 커뮤니티는 시각적인 자료가 있을 때 글을 읽는 재미가 훨씬 살아나며, 다채로운 게시판 환경을 조성할 수 있습니다.

## 3. 대댓글 (답글) 기능 (Nested Comments)
- **내용**: 현재 일렬로만 달리는 댓글 시스템을 개선하여, 특정 유저의 댓글에 꼬리를 무는 '답글'을 달 수 있도록 합니다.
- **기대 효과**: 유저들끼리 서로 영화 해석을 두고 깊이 있는 논쟁을 하거나 의견을 나누는 진짜 'Talks' 공간으로 거듭납니다.

## 4. 소셜 로그인 및 마이페이지 (Authentication)
- **내용**: 매번 닉네임을 수동으로 입력하는 방식 대신, Supabase Auth를 활용한 구글/카카오톡 소셜 로그인을 도입하고 유저 프로필 시스템을 구축합니다.
- **기대 효과**: "내가 쓴 글/댓글 모아보기", "내가 좋아요 누른 영화 목록" 등 유저 개인화 기능을 제공하여 진짜 완성형 서비스로 도약할 수 있습니다.
