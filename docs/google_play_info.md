## 2. 개인정보 처리방침 (Privacy Policy)
구글 플레이 등록 시 **개인정보 처리방침 URL**이 필수로 요구됩니다.
현재 웹사이트에 전용 페이지가 없다면 다음 중 하나의 방법을 선택해야 합니다.

1. **노션(Notion) 이용 (가장 빠름)**: 노션 페이지에 간단한 개인정보 처리방침을 작성한 뒤 '웹에서 보기' 링크를 만들어 제출합니다.
2. **웹사이트에 추가**: `movielobby.com/privacy` 와 같은 주소로 빈 페이지를 하나 만들어 연결합니다. (필요하시면 제가 템플릿을 만들어 웹사이트에 추가해 드릴 수 있습니다!)

## 3. 스크린샷 가이드

구글 플레이 콘솔에는 **최소 2장 이상 (최대 8장)**의 실제 앱 화면 스크린샷이 필요합니다.
현재 로컬에서 띄워두신 에뮬레이터나, Expo Go로 연결한 스마트폰에서 직접 캡처하시는 것이 가장 좋습니다.

**📸 추천하는 캡처 화면 4가지:**
1. **홈 화면 (트렌딩 영화)**: 영화 포스터들이 나열된 메인 화면 (다크 테마가 잘 보이도록)
2. **영화 상세 화면**: 특정 영화를 눌렀을 때 나오는 정보와 유튜브 트레일러 화면
3. **커뮤니티 (Talks)**: 가로 스크롤로 뜨는 핫한 영화와 최신 게시글 목록 화면
4. **리뷰 화면**: 유저들이 남긴 한줄평(빨간색 별점)이 보이는 화면

> 💡 **Tip:** 캡처한 이미지를 그대로 올려도 되지만, 이미지 주변에 여백을 두고 짧은 설명 문구를 추가하는 스토어 전용 이미지(목업)로 꾸미면 다운로드 전환율이 훨씬 높아집니다.
