# 기능 업데이트 완료: 스포일러 방지 및 페이징

요청하신 두 가지 핵심 커뮤니티 기능의 개발이 모두 완료되었습니다!

## 주요 변경 사항

### 1. 🚨 스포일러 방지 시스템
- **글쓰기 화면**: 본문 입력 창 아래에 `🚨 스포일러가 포함된 글입니다` 체크박스가 새롭게 추가되었습니다. 
- **게시판 목록**: 스포일러가 포함된 글은 게시판(BBS) 목록과 메인 홈의 실시간 최신 글 목록에서 제목 옆에 빨간색 `[스포일러]` 뱃지가 달립니다.
- **게시글 상세 보기**: 사용자가 실수로 스포일러 글을 클릭하더라도, 본문 내용이 블러(Blur) 처리되어 내용을 보호합니다. `🚨 스포일러 포함된 글입니다 (클릭해서 보기)` 버튼을 직접 눌러야만 실제 내용을 읽을 수 있습니다.

### 2. 📖 게시판 페이징 (페이지 번호)
- **페이지 버튼 적용**: 각 영화 카테고리의 `Talks` 게시판 맨 하단에 1, 2, 3... 형태의 동적 페이지 이동 버튼이 생성되었습니다.
- **최적화**: 한 페이지당 15개의 글만 보여주도록 렌더링을 최적화했으며, 데이터베이스 조회 시에도 전체 데이터를 가져오지 않고 해당 페이지 분량만 가져오도록(offset & limit) 적용하여 속도를 크게 개선했습니다.

## 테스트 방법
1. 로컬 서버(`npm run dev`)를 켭니다.
2. 톡스 게시판에서 새로운 글을 쓰며 **스포일러 포함**에 체크해 보세요.
3. 등록 후 목록에서 `[스포일러]` 뱃지가 나오는지, 상세 페이지에서 글이 가려져 있는지 확인합니다.
4. 게시판 페이지 하단에서 버튼을 눌러 다음 페이지로 잘 넘어가는지 테스트해 보세요!
